# EN
# PliserLoad Bot

Telegram inline bot for downloading tracks from SoundCloud and fetching lyrics from Genius.

## Usage
- `@bot track name` — download from SoundCloud
- `@bot track name text` — get lyrics

## Environment Variables (.env)
- `BOT_TOKEN` — Telegram bot token
- `STORAGE_CHAT_ID` — Private channel ID for audio storage
- `GENIUS_TOKEN` — Genius API access token

# RU

Телеграм инлайн бот для скачивания треков с SoundCloud и фетчинга текста с Geniusа.

## Как использовать?
- `@bot название_песни` - скачать трек с SoundCloud
- `@bot название_песни text` - получить текст песни.

## Environment Variables (.env)
- `BOT_TOKEN` — Токен телеграм бота (получить - @botfather)
- `STORAGE_CHAT_ID` — айди приватного канала/группы для хранилища файлов
- `GENIUS_TOKEN` — Genius API access token
